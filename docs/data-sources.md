# Источники данных по квитанциям ЖКУ (Россия, г. Хабаровск)

Исследование от 2026-09-23. Цель — оценить, откуда «Коммуналка» сможет забирать
начисления/квитанции/показания автоматически или полуавтоматически.

## 1. Хабаровские поставщики (локальные личные кабинеты)

### ВЦ по коммунальным платежам г. Хабаровска — khab-vc.ru, приложение «Мой ВЦ» (iOS/Android)
Основной расчетный центр города. Единая квитанция по коммунальным услугам и капремонту
(та самая структура строк, что в Excel пользователя).
- **Что можно забирать:** квитанция целиком (все статьи), история начислений (полный ЛК),
  список приборов учета, показания счетчиков.
- **Доступ:** без регистрации — последняя квитанция и показания; полный ЛК — по лицевому
  счету (регистрация, логин общий с сайтом). Разработчик ПО — ООО «Программы учета».
- **API:** публичного нет.

### ПАО «ДЭК» — Хабаровскэнергосбыт — dvec.ru
Электроэнергия, тепловая энергия, ГВС, ТКО (Хабаровский край).
- **Что можно забирать:** начисления и история расчетов в ЛК, показания приборов учета,
  **электронная квитанция (PDF) на e-mail** — доставляется раньше бумажной.
- **API:** публичного для физлиц нет; e-mail/PDF — готовый автоматический канал.

### МУП г. Хабаровска «Водоканал» — vodocanal.org
Холодная вода и водоотведение.
- **Что можно забирать:** показания, квитанции/начисления (ЛК примитивнее ВЦ и ДЭК;
  показания также принимает ВЦ: сайт, СМС +7(903)797-61-10, голосовой центр 380-303).

### ООО «Газпром межрегионгаз Дальний Восток» + сервис «Мой ГАЗ» — mrgdv.ru
Газоснабжение (квартиры и частный сектор).
- **Что можно забирать:** начисления за газ, квитанции, передача показаний (до 25 числа).
- Федеральный сервис «Мой ГАЗ» (мойгаз.рф) — единый ЛК Газпрома по стране.

### ООО «Газэнергосеть Хабаровск» — ges-khb.ru
Газ в частном секторе/СНТ (объект «Даниловского»).

### АО «ДГК», филиал «Хабаровская теплосетевая компания» — dvgk.ru
Теплоснабжение. Начисления обычно попадают в квитанцию ДЭК/ВЦ.

### ООО «РКЦ» — khb-rkc.ru
Расчеты за содержание жилого помещения (УК/ЖЭУ); ЛК через сайт ВЦ.

### НО «Региональный оператор — Фонд капитального ремонта» Хабаровского края — regoperatory.ru/fkr27
Взносы на капремонт. Квитанция, как правило, в составе единой квитанции ВЦ.

## 2. Федеральные сервисы-агрегаторы

### Госуслуги + «Госуслуги.Дом» (gosuslugi.ru, приложение)
- **Что можно забирать:** оплата ЖКУ по штрих-коду/лицевому счету, история оплат,
  в «Госуслуги Дом» — квитанция с расшифровкой по услугам и показания (для подключенных
  регионов/поставщиков).
- **API:** официальный закрытый (для организаций-партнеров).

### ГИС ЖКХ — личный кабинет жителя (dom.gosuslugi.ru)
- **Что можно забирать:** начисления, квитанции, показания поставщиков, подключенных
  к ГИС (покрытие по стране неполное).
- **API:** только для УК/РСО через аккредитованных интеграторов (договор), для физлица нет.

### «Квартплата+» — kvartplata.ru
Коммерческий агрегатор. В Хабаровске представлены: Водоканал (услуга №121562), газ и др.
- **Что можно забирать:** начисления по лицевому счету, передача показаний, оплата.
- **API:** нет.

### Банки: Сбербанк Онлайн, Т-Банк, ВТБ и др.
- **Что можно забирать:** сумма к оплате по коду плательщика/ЛС, история оплат;
  детализация по статьям квитанции обычно недоступна.
- **API:** открытый API только для юрлиц (Сбербизнес API и т.п.).

### ЭДО квитанций (СБИС, Такском)
Квитанции УК идут через ЭДО — но это B2B-канал, для физлица не применимо.

## 3. Выводы — что реально использовать

1. **Самый полный источник — ЛК ВЦ Хабаровска (khab-vc.ru / «Мой ВЦ»):** вся квитанция
   со всеми статьями, как в нашем Excel. Публичного API нет → варианты: ручной просмотр/
   выгрузка, или обращение к ООО «Программы учета» (владельцу ПО) насчет интеграции.
2. **Автоматический канал без договоренностей — e-mail:** ДЭК присылает PDF-квитанцию
   на почту раньше бумажной; почтовый ящик + парсер PDF = автозагрузка электроэнергии/
   тепла/ГВС/ТКО. То же потенциально для «Мой ГАЗ».
3. **Нейтральный путь для всех поставщиков — загрузка квитанции (PDF/фото) в наш сайт**
   с распознаванием (vision-модель раскладывает строки по статьям). Работает для любого
   поставщика и не зависит от чужих API.
4. Автопарсинг чужих ЛК (симуляция входа) технически возможен, но неофициален и может
   нарушать условия использования сервисов — не рекомендуется как основной путь.
