# Spec Delta

## Purpose

Позволяет владельцу вести список объектов недвижимости и настраивать для
каждого свой набор статей коммунальных платежей, включая собственные статьи
и реквизиты соответствия получателям платежей.

## ADDED Requirements

### Requirement: Набор статей платежей объекта
Система SHALL позволять для каждого объекта задавать собственный набор статей
платежей (из справочника: квартплата, электроэнергия, вода, ТКО, домофон,
капремонт, отопление, газ, ТВ), добавлять собственные статьи с произвольным
названием, переименовывать, удалять и менять их порядок, а также настраивать
видимость зон счётчиков (разделение воды на кухня/ванная). У каждой статьи
SHALL быть реквизит «Соответствие ГИС ЖКХ» — список подстрок-получателей
платежей (через «;»), используемый при распознавании квитанций.

#### Scenario: Разные наборы статей у объектов
- **WHEN** у объекта «Нордик» включена статья «Отопление», а у объекта «Вахова 4» — нет
- **THEN** при вводе данных «Нордик» показывает поле «Отопление», «Вахова 4» — не показывает

#### Scenario: Добавление статьи объекту
- **WHEN** пользователь включает объекту дополнительную статью из справочника
- **THEN** статья появляется в форме ввода для этого объекта

#### Scenario: Своя статья расходов
- **WHEN** пользователь добавляет собственную статью с названием, отсутствующим в справочнике
- **THEN** статья появляется в форме ввода и участвует в расчёте итога наравне со стандартными

#### Scenario: Заполнение соответствия ГИС ЖКХ
- **WHEN** пользователь указывает у статьи соответствие (например, «Водоканал;МУП города Хабаровска») и сохраняет настройки
- **THEN** соответствие сохраняется и используется при распознавании квитанций для поиска этой статьи

#### Scenario: Несколько получателей у одной статьи
- **WHEN** у статьи указано несколько получателей через «;»
- **THEN** при распознавании подходит любой из них
