# Proposal: utility-payments-site

## Why

Учёт коммунальных платежей по 5 объектам недвижимости ведётся в Excel-файле
(`Таблица (13).xlsx`): суммы по статьям вносятся вручную из квитанций, итоги
считаются «на коленке» в формулах вида `=4674.9+553.45+174+...`, год не
различается, доступ с телефона невозможен. Нужен простой веб-сайт с админкой:
ввод данных с любого устройства, автоматический итог, история по годам, простые
отчёты.

## What Changes

- Новое одностраничное веб-приложение (vanilla JS, без сборки) для учёта
  коммунальных платежей.
- 5 объектов на старте (Фурманова 193, Фурманова 177, Нордик, Вахова 4,
  Даниловского); набор статей у объектов разный и настраиваемый.
- Помесячный ввод: год + месяц (в т.ч. склеенные периоды вида
  «Август + Сентябрь»), платежи по статьям из квитанций, показания счётчиков
  (вода хол/гор, электроэнергия день/ночь) — справочно, без расчёта расхода.
- Автоматический пересчёт итога за месяц.
- Миграция существующей истории (~2 года) из Excel-файла.
- Простые отчёты: итог по всем объектам за месяц/год (столбики), динамика по
  выбранному объекту.
- Авторизация (только владелец): email + пароль, данные недоступны без входа.
- Хостинг: GitHub Pages (статика) + Supabase (Postgres, Auth, бесплатный tier).

## Capabilities

### New Capabilities

- `payment-entry`: ввод и редактирование помесячных платежей и показаний
  счётчиков по объектам; автоматический итог за месяц.
- `object-management`: объекты недвижимости и их набор статей платежей
  (добавление/редактирование).
- `reports`: простые отчёты — суммарные итоги по объектам за месяц/год и
  помесячная динамика по объекту.
- `data-migration`: однократный перенос истории из Excel-файла в базу.
- `auth`: вход по email/паролю; данные доступны только авторизованному
  владельцу.

## Impact

- Новый репозиторий GitHub (только для этого проекта), публикация на GitHub Pages.
- Внешняя зависимость: проект Supabase (Postgres + Auth, бесплатный tier) —
  заводится на этапе реализации, до публикации сайта.
- Существующий Excel-файл остаётся источником для миграции, после неё не нужен
  (архивная копия сохраняется).
