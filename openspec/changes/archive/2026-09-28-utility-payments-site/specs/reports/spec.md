# Spec Delta

## Purpose

Даёт владельцу простые отчёты по накопленным данным: суммарные итоги по всем
объектам за месяц или год и помесячную динамику по выбранному объекту.

## ADDED Requirements

### Requirement: Сводка по всем объектам
Система SHALL показывать отчёт с итоговой суммой по каждому объекту за выбранный
месяц и за выбранный год в виде столбчатой диаграммы или таблицы.

#### Scenario: Итоги за месяц по всем объектам
- **WHEN** пользователь открывает отчёт и выбирает год и месяц
- **THEN** он видит итоговую сумму по каждому объекту за этот месяц

#### Scenario: Итоги за год по всем объектам
- **WHEN** пользователь выбирает только год
- **THEN** он видит суммарные итоги по каждому объекту за этот год

### Requirement: Динамика по объекту
Система SHALL показывать помесячную динамику итоговых сумм по выбранному
объекту за выбранный год в виде простого графика или таблицы.

#### Scenario: График по объекту за год
- **WHEN** пользователь выбирает объект и год
- **THEN** он видит итог за каждый месяц года по этому объекту в хронологическом порядке
