# Spec Delta

## Purpose

Позволяет владельцу вести список объектов недвижимости и настраивать для
каждого свой набор статей коммунальных платежей.

## ADDED Requirements

### Requirement: Список объектов
Система SHALL хранить именованные объекты недвижимости. На старте система MUST
содержать 5 объектов: Фурманова 193, Фурманова 177, Нордик, Вахова 4,
Даниловского. Система SHALL позволять добавлять новые объекты и переименовывать
существующие.

#### Scenario: Просмотр объектов
- **WHEN** авторизованный пользователь открывает приложение
- **THEN** он видит список всех объектов

#### Scenario: Добавление объекта
- **WHEN** пользователь создаёт новый объект с именем
- **THEN** объект появляется в списке и доступен для ввода данных

### Requirement: Набор статей платежей объекта
Система SHALL позволять для каждого объекта задавать собственный набор статей
платежей (из справочника: квартплата, электроэнергия, вода, ТКО, домофон,
капремонт, отопление, газ, ТВ) и настраивать видимость зон счётчиков
(разделение воды на кухня/ванная).

#### Scenario: Разные наборы статей у объектов
- **WHEN** у объекта «Нордик» включена статья «Отопление», а у объекта «Вахова 4» — нет
- **THEN** при вводе данных «Нордик» показывает поле «Отопление», «Вахова 4» — не показывает

#### Scenario: Добавление статьи объекту
- **WHEN** пользователь включает объекту дополнительную статью из справочника
- **THEN** статья появляется в форме ввода для этого объекта
