# Spec Delta

## Purpose

Позволяет владельцу вносить и редактировать помесячные коммунальные платежи
и показания счётчиков по каждому объекту недвижимости, с автоматическим
пересчётом итога за месяц.

## ADDED Requirements

### Requirement: Ввод платежей за месяц
Система SHALL позволять авторизованному пользователю внести за объект за
выбранный год и месяц суммы платежей по статьям (квартплата, электроэнергия,
вода, ТКО, домофон, капремонт, отопление, газ, ТВ — набор зависит от объекта).
Система MUST автоматически вычислять итог за месяц как сумму внесённых статей.

#### Scenario: Успешный ввод месяца
- **WHEN** пользователь выбирает объект, год и месяц, вносит суммы по статьям и сохраняет
- **THEN** данные сохраняются, итог за месяц показывается сразу и равен сумме внесённых статей

#### Scenario: Частичный ввод
- **WHEN** пользователь вносит суммы не по всем статьям и сохраняет
- **THEN** пустые статьи трактуются как 0, итог считается только по внесённым статьям

#### Scenario: Редактирование ранее внесённого месяца
- **WHEN** пользователь открывает уже заполненный месяц, меняет суммы и сохраняет
- **THEN** сохраняются новые значения, итог пересчитывается

### Requirement: Ввод показаний счётчиков
Система SHALL позволять вносить за тот же период показания счётчиков: холодную
и горячую воду (по зонам: кухня/ванная — если у объекта они разделены) и
электроэнергию по тарифам день/ночь. Система MUST хранить показания как
справочные данные и SHALL NOT рассчитывать расход и стоимость по ним.

#### Scenario: Ввод показаний вместе с платежами
- **WHEN** пользователь заполняет месяц и вносит показания счётчиков
- **THEN** показания сохраняются и отображаются в истории рядом с платежами того же месяца

### Requirement: Склеенные периоды
Система SHALL поддерживать периоды, покрывающие несколько месяцев
(например, «Август + Сентябрь», «Ноябрь\Декабрь»), как отдельную запись с
собственным названием периода.

#### Scenario: Ввод за два месяца одной записью
- **WHEN** пользователь создаёт запись с названием периода, охватывающим несколько месяцев
- **THEN** запись сохраняется и показывается в истории как одна строка с этим названием
