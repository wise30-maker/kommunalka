# Spec Delta

## Purpose

Обеспечивает однократный перенос существующей истории платежей и показаний
(~2 года) из Excel-файла в базу данных сайта.

## ADDED Requirements

### Requirement: Импорт из Excel
Система SHALL предоставлять однократную процедуру миграции, переносящую из
Excel-файла все листы (объекты), записи месяцев (включая склеенные периоды),
суммы платежей по статьям и показания счётчиков. После миграции итоги,
вычисленные системой, MUST совпадать с итогами, хранившимися в Excel
(с точностью до копеек, пустые статьи = 0).

#### Scenario: Миграция всех листов
- **WHEN** процедура миграции выполняется над файлом `Таблица (13).xlsx`
- **THEN** создаются 5 объектов (Фурманова 193, Фурманова 177, Нордик, Вахова 4, Даниловского) со всеми месячными записями из соответствующих листов

#### Scenario: Проверка итогов после миграции
- **WHEN** пользователь открывает на сайте месяц, перенесённый из Excel
- **THEN** итог за месяц совпадает с итогом, который был записан в Excel для этого месяца

#### Scenario: Повторный запуск без дублей
- **WHEN** процедура миграции запускается повторно
- **THEN** данные не дублируются: существующие записи обновляются, а не создаются заново
