# Spec Delta

## Purpose

Помогает владельцу заполнять показания счётчиков: показывает предыдущее значение рядом
с полем ввода и умеет подставлять следующее показание по среднему расходу за год.
Показания остаются справочными — стоимость по расходу не рассчитывается.

## ADDED Requirements

### Requirement: Предыдущие показания рядом с полем ввода
Система SHALL показывать над названием каждого счётчика предыдущее показание — последнее
заполненное значение этого счётчика у этого объекта с указанием периода. Редактируемый
период в поиск предыдущего значения SHALL NOT включаться.

#### Scenario: Есть история показаний
- **WHEN** пользователь открывает форму месяца у объекта, где показания счётчика уже вводились
- **THEN** над названием счётчика видно предыдущее показание и период, к которому оно относится

#### Scenario: История пуста
- **WHEN** по счётчику ещё нет ни одного показания
- **THEN** вместо значения показывается «предыдущих показаний нет»

### Requirement: Заполнение показаний по среднему расходу за год
Система SHALL предоставлять действие «Заполнить по среднему за год», которое подставляет в
пустые поля показаний последнее известное значение плюс средний месячный расход за год,
указанный в форме. Средний расход MUST считаться по разницам между соседними показаниями
этого года, включая переход с прошлого года; нулевые разницы SHALL учитываться как расход 0,
убывающие (замена или сброс счётчика) SHALL игнорироваться. Заполненные вручную значения
SHALL NOT перезаписываться. Система MUST сообщить, сколько полей заполнено и где данных мало.

#### Scenario: Заполнение по среднему
- **WHEN** пользователь нажимает «Заполнить по среднему за год» при наличии истории показаний
- **THEN** пустые поля заполняются значением «предыдущее + средний расход», а введённые ранее значения остаются неизменными

#### Scenario: Расход не менялся
- **WHEN** в течение года показания счётчика не менялись
- **THEN** в поле подставляется то же значение, что и в предыдущем периоде, и система помечает это как «расход 0»

#### Scenario: Данных мало для расчёта
- **WHEN** по счётчику меньше двух показаний за год
- **THEN** поле остаётся пустым, а система сообщает, что данных для расчёта нет
