# Spec Delta

## Purpose

Помогает владельцу заполнять показания счётчиков: показывает предыдущее значение рядом
с полем ввода и умеет подставлять следующее показание по среднему расходу за год.
Показания остаются справочными — стоимость по расходу не рассчитывается.

## ADDED Requirements

### Requirement: Предыдущие показания рядом с полем ввода
Система SHALL показывать над названием каждого счётчика предыдущее показание — последнее
заполненное значение этого счётчика у этого объекта с указанием периода. Редактируемый
период в поиск предыдущего значения SHALL NOT включаться.

#### Scenario: Есть история показаний
- **WHEN** пользователь открывает форму месяца у объекта, где показания счётчика уже вводились
- **THEN** над названием счётчика видно предыдущее показание и период, к которому оно относится

#### Scenario: История пуста
- **WHEN** по счётчику ещё нет ни одного показания
- **THEN** вместо значения показывается «предыдущих показаний нет»

### Requirement: Заполнение показаний по среднему расходу
Система SHALL предоставлять действие «Заполнить по среднему (последние 3 месяца)», которое
подставляет в пустые поля показаний последнее известное значение плюс средний месячный расход.
Средний расход MUST считаться по последним трём промежуткам между показаниями: берутся последние
четыре показания счётчика (без учёта редактируемого периода), суммарная разница делится на число
промежутков. Нулевая разница SHALL трактоваться как расход 0, убывающая (замена или сброс
счётчика) SHALL NOT участвовать в расчёте. Заполненные вручную значения SHALL NOT
перезаписываться. Система MUST сообщить, сколько полей заполнено и где данных мало.

#### Scenario: Заполнение по среднему
- **WHEN** пользователь нажимает «Заполнить по среднему (последние 3 месяца)» при наличии истории показаний
- **THEN** пустые поля заполняются значением «предыдущее + средний расход по последним трём промежуткам», а введённые ранее значения остаются неизменными

#### Scenario: Расход не менялся
- **WHEN** в последних показаниях счётчика разница нулевая
- **THEN** в поле подставляется то же значение, что и в предыдущем периоде, и система помечает это как «расход 0»

#### Scenario: Показания убывают
- **WHEN** последнее показание меньше предыдущего (замена или сброс счётчика)
- **THEN** такие разницы в расчёт среднего не попадают

#### Scenario: Данных мало для расчёта
- **WHEN** по счётчику меньше двух показаний
- **THEN** поле остаётся пустым, а система сообщает, что данных для расчёта нет
