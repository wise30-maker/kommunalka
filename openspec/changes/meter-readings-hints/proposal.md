# Proposal: Подсказки по показаниям счётчиков

## Зачем
Показания вводятся вручную каждый месяц, и приходится смотреть в историю, чтобы вспомнить
предыдущее значение. Нужно: (1) видеть предыдущее показание прямо в форме месяца,
(2) одной кнопкой заполнять показания по среднему расходу за текущий год.

## Что делаем
В разделе «Показания счётчиков» формы периода:
1. **Над названием каждого счётчика** — строка «предыдущие показания: <значение> (<месяц>)»
   из последнего периода объекта, где эти показания заполнены (редактируемый период в расчёт
   не берётся). Если истории нет — «предыдущих показаний нет».
2. **Кнопка «Заполнить по среднему (последние 3 месяца)»** — для незаполненных полей подставляет
   последнее показание плюс средний месячный расход, рассчитанный по последним трём промежуткам
   между показаниями: берутся последние 4 показания, суммарная разница делится на число
   промежутков. Нулевая разница = расход 0; убывание (замена или сброс счётчика) в расчёт не идёт.
   Уже введённые значения не перетираются. Под кнопкой появляется отчёт: сколько полей заполнено,
   где расход 0, где данных мало.

## Архитектура
- `js/readings.js` — расчёты (`series`, `previous`, `avgMonthly`, `suggest`); работает и в браузере,
  и в Node, поэтому проверяется стендом.
- `tools/readings_test.js` — прогон расчётов по реальным данным `migrate/data.json`.
- Форма периода в `js/app.js` использует модуль; данные объекта догружаются всегда (нужны для подсказок).

## Границы
- Показания остаются справочными: система по-прежнему не считает стоимость по расходу — она лишь
  подсказывает следующее значение.
- Если по счётчику меньше двух показаний, средний расход не построить — кнопка честно сообщает,
  что данных мало, и оставляет поле пустым.
